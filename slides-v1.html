O1 · 說出 VLA 的定義，以及它和 LLM / VLM 的關係

從 LLM → VLM → VLA

LLM文字進、文字出
VLM影像 + 文字進、文字出
VLA影像 + 指令進、機器人動作出
  • VLA 是把 VLM 微調成直接輸出機器人動作的模型vla
  • 輸入相機影像與自然語言指令，輸出下一步動作vla
  • 就像讓一個很會看圖說話的人，改成看圖動手
名詞小卡
VLMVision-Language Model，看圖也讀文字的大模型，例如 PaLI-X、PaliGemma
VLAVision-Language-Action，在 VLM 上多學一種輸出：機器人動作
🗒 先用 LLM 當錨點，觀眾都熟。
O1 · 說出 VLA 的定義，以及它和 LLM / VLM 的關係

為什麼要借用 VLM？

  • VLM 從網路圖文學到常識，可以轉移給機器人vla
  • RT-2 能聽懂機器人資料裡沒有的指令，例如把東西放到某個數字上rt2
  • 還會簡單推理：挑最小的物體、拿石頭當鐵鎚rt2
  • 未見情境成功率 62，舊 policy RT-1 只有 32，約 2 倍rt2
  • 但限制是：網路資料不會教機器人新動作rt2
名詞小卡
policy機器人的「決策函式」：看到當下狀態，決定要做什麼動作
🗒 強調：知識會轉移，但動作技能還是要靠機器人資料。
O2 · 理解動作怎麼變成模型輸出：離散 token vs 連續動作

動作怎麼變成 token？

  • RT-2 的動作：6-DoF 末端位移/旋轉 + 夾爪 + 終止rt2
  • 每個連續維度切成 256 個 bin，一個動作變 8 個整數rt2action-representation
  • 把整數寫成 token，就能用語言模型的 next-token 預測來訓練action-representation
  • OpenVLA 覆寫 Llama tokenizer 最少用的 256 個 token 放動作openvla
  • bin 範圍取第 1 到第 99 百分位，避免極端值openvla
名詞小卡
DoFDegree of Freedom 自由度；6-DoF = 3 個位移 + 3 個旋轉
🗒 類比：把連續溫度四捨五入成整數刻度，再當成單字來預測。
O2 · 理解動作怎麼變成模型輸出：離散 token vs 連續動作

另一條路：直接輸出連續動作

  • Octo 用 diffusion action head，經 20 步去噪產生連續動作continuous-action-heads
  • π0 在 PaliGemma 旁掛 300M 的 action expert，用 flow matchingcontinuous-action-headspi0
  • 從雜訊出發一步步修正成動作，能表示「多種合理做法」continuous-action-heads
  • 像雕刻：從一塊亂石慢慢修成想要的形狀
名詞小卡
diffusion從隨機雜訊開始、反覆去噪生成資料的方法（影像生成常用）
flow matching學一個把雜訊「流」到資料的速度場，概念類似 diffusion 但更直接
🗒 不需講數學，只講直覺。

O3 · 知道 VLA 的資料從哪來：跨機體資料與 co-fine-tuning

資料從哪來？跨機體學習

  • Open X-Embodiment：21 個機構、22 種機器人、527 種技能oxe
  • RT-X 用多種機器人資料訓練，各台機器人都變強oxecross-embodiment
  • Octo 挑 800k、OpenVLA 挑 970k 條軌跡來預訓練cross-embodiment
  • RT-1 的結論：資料多樣性比資料量更重要cross-embodiment
名詞小卡
embodiment機器人的「身體」：手臂型號、感測器、動作空間
正遷移positive transfer，學 A 的資料反而讓 B 變好
🗒 類比：學過很多種樂器的人，學新樂器更快。
O3 · 知道 VLA 的資料從哪來：跨機體資料與 co-fine-tuning

Co-fine-tuning：別讓 VLM 失憶

  • 微調時同時放機器人資料和網路圖文資料（如 VQA）co-fine-tuning
  • RT-2 中機器人資料約佔 50%（PaLI-X）到 66%（PaLM-E）co-fine-tuning
  • 55B 模型泛化分數：co-fine-tune 63，只用機器人資料 52co-fine-tuning
  • 只餵機器人資料，模型可能忘掉網路常識co-fine-tuning
名詞小卡
co-fine-tuning微調時混合新任務資料與原本的預訓練型資料一起訓練
O4 · 理解為什麼需要 action chunking 才能高頻控制

大模型太慢？Action chunking

  • RT-2 55B 每步都要跑一次大模型，只有 1-3 Hzaction-chunkingrt2
  • OpenVLA 在一張 RTX 4090 約 6 Hzopenvla
  • π0 一次輸出 50 步動作，控制頻率可達 50 Hzaction-chunkingpi0
  • 把「想一次」和「動很多下」分開action-chunking
名詞小卡
控制頻率每秒送給馬達幾次指令（Hz）；越高動作越順
action chunk一次預測的一整段未來動作
